Atelier is now open source, at github.com/atelierstore/Atelier, and its updates, website and install server moved to atelierstore.app. Apps signed with an Apple ID keep their App Groups, so a widget or extension shares its app's data again.

## New

- Atelier's code is public, and Atelier reads its own source from the public repo, so its updates no longer need a GitHub sign-in.
- Apps signed with an Apple ID keep their App Groups: Atelier asks Apple for the app's own App Group names under your Apple ID, so its widgets and extensions see the app's data. Custom Install › Advanced › Share App Groups turns it off for an app.
- The website is at [atelierstore.app](https://atelierstore.app), and installs through the iOS alert, Apple ID sign-in and GitHub sign-in go through api.atelierstore.app.
- The website has a Donate button, which opens Atelier's page on Ko-fi (#5).

## Behind the scenes

- Builds and releases run on GitHub Actions (#1), and each build's IPAs can be installed from the website for 7 days (#4, #6).

## Updating from 0.5.1-alpha

Atelier 0.5.1 looks for updates at its old address, so it won't offer this one. Install this IPA over it, signed with the same certificate and profile; your apps, certificates and settings stay. Then remove the old Atelier source in Browse › Manage Sources: Atelier lists itself from the new one.

## Installing

Get Atelier from [its website](https://atelierstore.app), or sign the IPA below with your own certificate and install it with a tool such as Sideloadly, Feather, AltStore or SideStore ([guide](https://github.com/atelierstore/Atelier/blob/main/docs/install.md)). Requires iOS 17 or later.

## Known limits

- Background installs and automatic updates need Wi-Fi and LocalDevVPN, and renewing needs LocalDevVPN.
- Apps signed with an Apple ID only install through the setup (Settings › Installs › Setup).
- A free Apple ID allows 3 apps at a time on your iPhone and 10 new apps a week. Renewing an app takes one of the 10 again once its App ID has ended, about every 10 days.
- Atelier itself can't be signed with an Apple ID.
- Apple has refused some free Apple ID sign-ins on and off since October (error -80045).
- Atelier updates itself only with a profile for the App ID it was installed with.
- Atelier's releases are pre-releases for now, so keep Include Pre-releases on for its source.
