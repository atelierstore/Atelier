Re-sign apps whose certificate died, one at a time or all at once. OwnStore now checks for updates in the background, and with Direct installs it can install them by itself and keep an app's data when it has to be reinstalled. GitHub repos work as sources too.

## What's new

- **Re-sign apps whose certificate died.** Apps whose certificate was revoked, has expired or expires within 14 days wait in a new Re-sign section at the top of the Library. Re-sign or Re-sign All signs them again with a certificate that still works and installs them over the old ones. The notifications about a dying certificate now take you there. (#92, #95)
- **Keep an app's data when it has to be reinstalled.** iOS can't replace an app with one signed for another App ID. With Direct installs, OwnStore copies the app's data, deletes it, installs it again and puts the data back. When iOS refuses to replace an app, OwnStore now says why and offers another certificate or a copy, and it asks before any change that means deleting an app. (#77, #97)
- **Updates.** The Library has an Updates section with Update All, a badge and Skip This Version, and updates keep the certificate each app was installed with. In the background, OwnStore checks your sources, tells you about new updates and news, and downloads updates ahead on Wi-Fi, so Update only signs and installs. (#65, #77, #91)
- **Background installs and automatic updates (Direct installs).** Installs and updates keep going after you leave OwnStore, with their progress on the Lock Screen and in the Dynamic Island (iOS 26 and later). Turn on Install updates automatically in Settings › Updates, and updates install on Wi-Fi with LocalDevVPN connected, whenever iOS lets OwnStore run. (#73)
- **GitHub repos as sources.** Add `owner/repo` and its releases' IPAs become versions, with pre-releases if you want them and a choice of build when a release has several. Sign in with one or more GitHub accounts to add private repos, in Settings or from your picture at the top right of Add Source's GitHub tab. (#71, #89, #90)
- **Links and files from other stores.** AltStore, SideStore and Feather links open in OwnStore: sources, app installs (it asks first), app pages and searches, Feather's certificate imports, and certificate requests from apps such as LiveContainer. .ipa and .tipa files open in OwnStore and install straight away. (#94)
- **Install older versions** from an installed app's page, and one Install button everywhere, with a progress ring and Waiting while it's queued. (#79)
- **One app page** from Browse and the Library, featured apps inside each source's card, big News cards, and Add Source on one screen. (#82, #85, #86)
- **Pairing steps in a Live Activity.** While OwnStore pairs your iPhone for Direct installs, each step and the code show on the Lock Screen and in the Dynamic Island. (#68)

## Fixes

- Direct installs check the profile signed into the app being installed, not the default certificate's, so they no longer stop an update iOS would accept. (#88)
- Sign Again With opens a full-width sheet, so certificates' details fit. (#80)

## Behind the scenes

- In a source, each release's What's New is the first paragraph of its notes, as plain text. (#70)
- Build numbers only go up, and test builds count as newer than the last release. (#98)
- A release is published by merging its notes, which have to mention every pull request since the release before. (#100)

## Updating from 0.1.0-alpha

OwnStore can't update itself yet (#24). Sign this IPA with the same certificate and profile as the OwnStore you have, and install it over it: your sources, certificates and Library stay. With a profile for another App ID, iOS won't replace it, and you'd have to delete OwnStore first and set it up again.

## Installing

OwnStore has to be signed and installed the first time with another tool, such as Sideloadly, Feather, AltStore or SideStore. See [docs/install.md](https://github.com/atelierstore/Atelier/blob/main/docs/install.md). Requires iOS 17 or later.

The IPA below is unsigned. Sign it with your own certificate.

## Known limits

- Direct installs need LocalDevVPN connected and Wi-Fi.
- Prompted installs show iOS's install alert for each app.
- Without Direct installs, an app that has to be reinstalled for another App ID loses its data.
- OwnStore can't update itself yet (#24).
