OwnStore can now update itself. Installing is simpler, with no method to pick and an optional one-time setup for background installs and automatic updates. Each source can now show or hide its pre-releases.

## What's new

- **OwnStore updates itself.** Its updates show in the Library like any app's, and your sources, certificates and apps stay.
- **One way to install.** There's no install method to pick anymore. Tap Finish Setting Up in Settings › Installs to add background installs, automatic updates, and keeping an app's data when it's signed again.
- **Simpler Settings.** Settings is regrouped around installs, and GitHub accounts moved to Browse › Manage Sources.
- **Pre-releases per source.** Every source has an Include Pre-releases switch, and betas are marked BETA.
- **Install a Copy…** of an installed app, as a separate app with its own data.
- **Real icons.** Installed apps show the icon from the app itself, not their source's picture.
- **Faster Browse** at launch, and app pages show the full subtitle.

## Fixes

- Tapping the source on an app's page no longer freezes OwnStore.
- Apps whose IPA has a different bundle ID than their source lists now show as installed.
- Open Settings, while pairing, goes to Settings' main page.

## Updating from 0.2.0-alpha

Install this IPA over your current OwnStore, signed with the same certificate and profile, and everything stays. If you'd set up Direct installs, the new setup is already done. Reinstall is gone: OwnStore no longer keeps signed copies of your apps, and deletes the old ones.

## Installing

Sign the IPA below with your own certificate, and install it with a tool such as Sideloadly, Feather, AltStore or SideStore ([guide](https://github.com/atelierstore/Atelier/blob/main/docs/install.md)). Requires iOS 17 or later.

## Known limits

- Background installs and automatic updates need Wi-Fi and LocalDevVPN.
- OwnStore updates itself only with a profile for the App ID it was installed with.
- OwnStore's releases are pre-releases for now, so keep Include Pre-releases on for its source.
