OwnStore is now Atelier, with a new name and icon. Atelier is a new app that starts empty: set it up, install your apps again from it, then delete OwnStore. Every list of apps now has a search field.

## What's new

- **Atelier.** OwnStore's new name, with the easel icon, also in dark and tinted. It's a separate app with its own links (`atelier://`) and data, so it installs next to OwnStore.
- **Search everywhere.** A source's apps, a category, Manage Sources, the Library and Install History each have a search field.
- **Installing over an app already on your iPhone.** With Direct installs, Atelier first checks who signed it. If it's one of your certificates, Atelier signs with that one; otherwise it asks whether to import that certificate, install a copy, or delete the app and install.
- **What to try when iOS's install service doesn't answer.** Settings › Installs › Setup says what to do, with a button for it.
- **Updating Atelier itself** asks you to go to the Home Screen, with a button, so iOS can finish installing it.
- **Release news.** Atelier's own source announces each release in Browse's news, starting with this one.

## Fixes

- Direct installs follow iOS's install service when it moves off its usual port, which made the Setup's check say it refused.
- The Setup's Live Activity only shows during the first setup, and without a sound.
- A certificate deleted and imported again gets its apps back, with their updates.

## Moving from OwnStore

Atelier doesn't update OwnStore, and nothing carries over:

1. Install Atelier as below. It goes next to OwnStore.
2. Set it up: add your sources, import your certificates with their passwords, pair again, and sign in to GitHub.
3. Reinstall each app through Atelier with the certificate it was signed with. That installs over it and keeps its data. Copies OwnStore made stay as they are.
4. Delete OwnStore.

## Installing

Sign the IPA below with your own certificate, and install it with a tool such as Sideloadly, Feather, AltStore or SideStore ([guide](https://github.com/atelierstore/Atelier/blob/main/docs/install.md)). Requires iOS 17 or later.

## Known limits

- Background installs and automatic updates need Wi-Fi and LocalDevVPN.
- Atelier updates itself only with a profile for the App ID it was installed with.
- Atelier's releases are pre-releases for now, so keep Include Pre-releases on for its source.
